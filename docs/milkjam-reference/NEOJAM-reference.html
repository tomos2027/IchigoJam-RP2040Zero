NEOJAM BASIC リファレンス ver 1.6.1

ベース: IchigoJam BASIC 1.6.1 (4K版) ／ 対象: Waveshare RP2040-Zero版 NEOJAM (RP2040・NTSCコンポジット出力専用)
・プログラム領域 4096バイト、配列変数 [0]〜[357] の358個、内蔵フラッシュに25本保存 (0〜24)
・映像は NTSC コンポジット (GP3、75Ω+560pF の外部回路経由) 専用。VIDEO 9/10 で 16 色カラー表示可。CPU は 157.5MHz 駆動
・基板内蔵 WS2812 (GP16) は起動・エラー表示と共用で WS.LED 0 でも制御可。外部 WS2812 は WS.LED 7 (GP15) または WS.LED 8 (GP2・OUT7兼用)
・I2Cバスは GP4 (SDA) / GP5 (SCL)。
・記法: { } で囲んだ引数は省略可。コマンドの後ろの / 〜 は読み方 (ふりがな)
