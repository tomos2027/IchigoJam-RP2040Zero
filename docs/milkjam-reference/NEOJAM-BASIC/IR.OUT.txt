IR.OUT
NEOJAM
-----------------------------------------------------------
[ 機能 ]
赤外線リモコンの信号を送信します。

[ コマンド 書式 ]
IR.OUT <ポート>,<データ>{,<リピート>}
IR.OUT <ポート>,[<配列番号>]{,<リピート>}

[ 例 ]
10 IR.OUT 1,#807F
20 IR.OUT 2,[0]

[ 解説 ]
NEC 形式の赤外線信号を送信します (4K 版拡張)。
<ポート> は 1-6 で OUT1～6 端子 (GP8～GP13) に対応し、
赤外線 LED を接続します (駆動強度 12mA に設定されます。
OUT ピン → 抵抗 47-100Ω → LED → GND で直結可。
長距離はトランジスタ駆動を推奨)。
38kHz キャリアは PWM 高速モードで生成します
(PWM 5,630,-1260 と同じ。実際は約 38.46kHz)。

<データ> は 16bit 値で、上位 8bit がアドレス (カスタムコード)、
下位 8bit がコマンド (データ) です
(例: #807F = アドレス #80・コマンド #7F)。
実際の送信は NEC 形式 (addr, ~addr, cmd, ~cmd の
LSB ファースト) で行われます。
アドレス #80 以上は 16bit 符号付きで負数になるため
#8001-65536 のように指定して下さい。

IR.OUT <ポート>,[n] の形式では、IR.IN で受信した結果
([n]～[n+3] の 4 バイト + モード [n+6]) をそのまま再送します
(標準 NEC・NEC 拡張を自動判別します)。

<リピート> は送信回数です (省略時 1。完全フレームを
約 40ms 間隔で連送。ESC で中断可)。
ポート範囲外や SDON 中の共有ピン (OUT1・OUT3・OUT4) は
エラー (Illegal argument) になります。
IR.OUT は PWM スライスを 38kHz 高速モードに設定するため、
同じペア (OUT1/2・OUT3/4・OUT5/6) のもう一方の
PWM 周期が変わります。
