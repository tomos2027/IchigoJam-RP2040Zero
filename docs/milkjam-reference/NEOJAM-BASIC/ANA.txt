ANA
NEOJAM
-----------------------------------------------------------
[ 機能 ]
アナログ入力の電圧を読み取ります。

[ コマンド 書式 ]
ANA({<数>})

[ 例 ]
?ANA(1)

[ 解説 ]
外部入力の電圧 (0～3.3V) を 0～1023 の数値で返します。
NEOJAM では次の端子が利用できます。

    0・9  本体ボタン (GP28・BTN)
    1     IN1 (GP27)
    2     IN2 (GP26)

<数> を省略した場合は ANA(0) と同じです (ボタン)。
それ以外の数を指定した場合は 0 を返します。
GP26～GP28 が ADC に対応しています (GP29 は未使用)。
