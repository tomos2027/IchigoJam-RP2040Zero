WS.MODE
NEOJAM
-----------------------------------------------------------
[ 機能 ]
WS.LED が読み込むデータの形式と開始位置を設定します。

[ コマンド 書式 ]
WS.MODE <mode>{,<offset>}

[ 例 ]
10 WS.MODE 1
20 WS.MODE 1,F*64
30 WS.MODE 3

[ 解説 ]
8x8 / 16x16 の WS2812 マトリックス (NeoMatrix) や
パラパラアニメに対応するため、WS.LED が読み込む
ピクセルデータの形式 (モード) と開始位置 (オフセット) を
設定します。mode 3 では BASIC 配列を使用しない
専用バッファ (8KB・最大 2730px) を使えます。

    mode 0  配列 3 要素/1px: [o]=G [o+1]=R [o+2]=B
            (各 0-255。従来互換・既定)
    mode 1  配列 1 要素/1px: RGB332 (RRRGGGBB・0-255)
    mode 2  配列 1 要素/2px: 下位バイト=1 個目、
            上位バイト=2 個目 (RGB332)
    mode 3  専用バッファ: GRB 3 バイト/px
            (WS.PUT で書込み)

<offset> は WS.LED が読み込む開始位置です
(mode 0-2 は配列インデックス 0-357、mode 3 は
バッファのピクセル位置 0-2729。省略時 0)。

モード/オフセットの設定は CLV 実行時と起動時に
モード 0/オフセット 0 へ戻ります。
<offset> を省略すると 0 に戻ります (フレーム表示時は
毎回指定して下さい)。

mode 3 では WS.LED の個数上限が配列の 119 を超え
2730px まで拡張されます (オフセット以降の残り
ピクセル数に自動切詰め)。
モード/オフセットの組合せで配列 [0]-[357] を超える
読み込みになる場合も、LED 数は自動的に切り詰められます。

repeat 指定時も毎回オフセットから同じデータを
再読み込みします (タイル送信の動作は変わりません)。

mode 2 で上位バイトを含む値 (#8000 以上) は BASIC 上では
負の数になります (#F00F のような16進表記、または
65536 を加えた値で指定して下さい)。

WS.PUT・RGB を参照して下さい。
