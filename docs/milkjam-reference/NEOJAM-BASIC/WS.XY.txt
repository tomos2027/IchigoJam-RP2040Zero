WS.XY
NEOJAM
-----------------------------------------------------------
[ 機能 ]
WS2812 マトリックスへ x,y 座標を指定して
1 ピクセル書き込みます。

[ コマンド 書式 ]
WS.XY <x>,<y>,<R>,<G>,<B>

[ 例 ]
10 WS.MATRIX 8,8
20 WS.XY 0,0,255,0,0
30 WS.XY 7,7,0,0,255
40 WS.LED 7,64

[ 解説 ]
WS.MATRIX で設定した寸法に従い、画面上の
座標 (x,y) に対応するピクセルへ R/G/B 各
0-255 で色を書き込みます。

    <x>  0 〜 w-1 (左から右)
    <y>  0 〜 h-1 (上から下)

範囲外の x,y は無視されます (エラーになりません)。
R/G/B が 0-255 の範囲外の場合はクランプされます
(負→0、255 超→255)。

データは専用バッファ (WS.MODE 3) に GRB 順で
格納されます。WS.XY を実行すると自動的に
mode 3 になります (オフセットは維持)。

複数フレームを描く場合は、WS.MATRIX を最初に
1 回だけ実行し、フレーム切替は
WS.MODE 3,F*64 の後に WS.XY で描画します。

WS.MATRIX・WS.MODE・WS.PUT を参照して下さい。
