RENUM
NEOJAM
-----------------------------------------------------------
[ 機能 ]
行番号を振り直します。

[ コマンド 書式 ]
RENUM {<数1>{,<数2>}}

[ 例 ]
RENUM
RENUM 100,10

[ 解説 ]
プログラムの行番号を <数1> (省略時は 10) から
<数2> (省略時は 10) 刻みで振り直します。
GOTO・GOSUB の飛び先が行番号で書かれている場合は
自動で書き換えられない場合がありますのでご注意下さい
(@ラベルは影響ありません)。
