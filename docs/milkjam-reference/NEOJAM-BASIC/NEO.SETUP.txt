NEO.SETUP
NEOJAM (カラー表示・テスト実装)
-----------------------------------------------------------
[ 機能 ]
NEO.* (WS2812 ストリップ) のポートと LED 数を設定します。

[ コマンド 書式 ]
NEO.SETUP <ポート>{,<LED 数>}

[ 例 ]
NEO.SETUP 7,16

[ 解説 ]
<ポート> は WS.LED と同じ 0-11
(0=基板内蔵 GP16、7=外部 WS2812 GP15 など)。
<LED 数> は 1-2730 (省略時は現状維持、初期値 8)。
実行すると専用バッファ (WS.MODE 3) モード・オフセット 0 に
なります。色は 16bit RGB555 パック色
(NEO.RGB(r,g,b) 等の色関数で作成)。
NEO.PIXEL・NEO.STRIP・NEO.REFRESH も参照して下さい。
詳細は docs/NEO_JA.md を参照して下さい。
