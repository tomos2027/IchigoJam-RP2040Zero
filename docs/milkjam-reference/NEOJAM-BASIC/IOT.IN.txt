IOT.IN
NEOJAM
-----------------------------------------------------------
[ 機能 ]
sakura.io モジュールからデータを受信します。

[ コマンド 書式 ]
IOT.IN()

[ 例 ]
A=IOT.IN()

[ 解説 ]
I2C (GP4=SDA・GP5=SCL、アドレス 79=#4F) 接続した
sakura.io モジュールの
データ受信コマンド (Q=#30) を用いて
受信キュー先頭にあるデータを得ます。
受信データがない場合は 0 を返します。
IOT.OUT で送信したデータの応答受信にも使用します
(IOT.OUT を参照)。
