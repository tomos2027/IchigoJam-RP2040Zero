LIST
NEOJAM
-----------------------------------------------------------
[ 機能 ]
プログラムを表示します。

[ コマンド 書式 ]
LIST {<行番号1>{,<行番号2>}}

[ 例 ]
LIST
LIST 30

[ 解説 ]
プログラムを表示します。USB キーボードでは F4 に
割り当てられています。

<行番号1> で 1 行表示、<行番号1> がマイナスでその行まで表示、
<行番号2> 指定でその行まで表示、<行番号2> が 0 の時は
終わりまで表示します。ESC で途中停止します。
