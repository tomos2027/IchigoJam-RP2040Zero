LED
NEOJAM
-----------------------------------------------------------
[ 機能 ]
ランプを点灯・消灯します。

[ コマンド 書式 ]
LED <数>

[ 例 ]
LED 1
LED 0

[ 解説 ]
GP2 (LED 端子) に接続したランプを点灯・消灯します。
<数> は 0 以外で点灯、LED 0 で消灯です。
LED は OUT 7 と共通の端子です (OUT 7,n と LED n は同じ動作)。
WS.LED のポート 8 も同じピンです
(GP2 に WS2812 を接続すれば WS.LED 8,n で点灯します)。

基板内蔵の WS2812 (GP16) は LED コマンドでは
制御できません。内蔵 WS2812 は起動時の緑点滅・
エラー時の赤高速点滅と共用で、WS.LED 0,n で制御します。
