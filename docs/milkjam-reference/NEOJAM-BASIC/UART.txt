UART
NEOJAM
-----------------------------------------------------------
[ 機能 ]
シリアル (UART) の入出力を設定します。

[ コマンド 書式 ]
UART <数1>{,<数2>}

[ 例 ]
UART 0
UART 2,0

[ 解説 ]
<数1> でシリアル出力の設定をします (GP0 TX)。

    0   オフ
    1   PRINT のみ
    2   PRINT/LC/CLS/SCROLL (デフォルト)
    3   PRINT のみ (改行コード \r\n)
    +4  入力エコーバック
    +8  画面表示オフ

<数2> でシリアル受信の設定をします (省略時 1)。

    0   オフ
    1   オン
    +2  ESC 無効
    +4  CR 変換 (13→10)

通信速度は BPS で変更できます。
