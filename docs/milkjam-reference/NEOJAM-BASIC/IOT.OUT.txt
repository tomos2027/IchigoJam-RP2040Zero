IOT.OUT
NEOJAM
-----------------------------------------------------------
[ 機能 ]
sakura.io モジュールへデータを送信します。

[ コマンド 書式 ]
IOT.OUT <値>
IOT.OUT <送信内容>,<長さ>
IOT.OUT <送信内容>,<長さ>,<フラッシュ>

[ 例 ]
IOT.OUT 1
IOT.OUT "NEOJAM ",7

[ 解説 ]
I2C (GP4=SDA・GP5=SCL、アドレス 79=#4F) 接続した
sakura.io モジュールの
データ即時送信コマンド (Q=#21) を用いて値を送出します。
送出時の ch は 0 固定です。

<送信内容> には仮想メモリの番地や文字列を指定できます。
<長さ> は 8 の倍数で、128 バイトを超える場合は
128 バイト毎に送信します。
<フラッシュ> に 0 以外を指定するとモジュール内の
フラッシュへも書き込まれます。

受信は IOT.IN を参照して下さい。
