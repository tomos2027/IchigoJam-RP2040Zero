FILES
NEOJAM
-----------------------------------------------------------
[ 機能 ]
プログラムの一覧を表示します。

[ コマンド 書式 ]
FILES {<数1>{,<数2>}}

[ 例 ]
FILES
FILES 0

[ 解説 ]
保存されているプログラムの一覧を表示します。
ESC キーで途中停止します。

NEOJAM の保存先は次のとおりです。

    0～24     内蔵フラッシュ (25 本)
    100～131  外部 EEPROM (32 本)
    200～299  SD カード (SDON 中のみ)

SDON 中は SD カードの一覧を、SDOFF 中は
フラッシュ・EEPROM の一覧を表示します。
<数1> を 0 に指定すると全て表示します。
番号や範囲を明示した場合は従来どおりの表示になります。
