KBD
NEOJAM
-----------------------------------------------------------
[ 機能 ]
キーボード配列を変更します。

[ コマンド 書式 ]
KBD <配列>

[ 例 ]
KBD 1

[ 解説 ]
USB キーボードの配列を変更します。
設定はフラッシュに保存され、次回起動時も維持されます。

    0  英語 (US) キーボード
    1  日本語 (JIS) キーボード

KBD 1 の状態ではローマ字かな入力が使えます。
「変換」キー (または Ctrl+Space) でかなモードに入り、
ローマ字入力がかなに変換されます。Esc で解除されます。
