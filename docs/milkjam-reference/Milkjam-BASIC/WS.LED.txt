WS.LED
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
RGB LED (WS2812B) を制御します。

[ コマンド 書式 ]
WS.LED <ポート>,<LED 個数>{,<リピート>}

[ 例 ]
10 WS.LED 1,3
20 WS.LED 0,1

[ 解説 ]
WS2812B (WS2811・WS2812・WS2813・SK6812 など同仕様も可) を
PIO 駆動で制御します。長い LED テープを接続しても
表示や USB キーボードが乱れません。
WS2812B の DIN を接続し、GND・VCC (5V) を接続します。
複数個接続する場合は DOUT と DIN を順に接続します。

<ポート> で出力先を選択します (ポート選択式・4K 版拡張)。

    0  内蔵 LED (CYW43・基板上の LED。単色のため
       配列 [0]～[2] のいずれかが 0 以外で点灯)
    1-6  OUT1～6 端子
    7  LED 端子 (GP2)

<LED 個数> 分の色データを配列 [0] 以降へ、
WS2812B の場合は 緑(G)・赤(R)・青(B) の順で
0～255 の値を入れてから実行します
(WS2811・WS2813 は 赤・緑・青 の順)。

    LED 1   2   3 ...
      [0] [3] [6] ... 緑(G・0～255)
      [1] [4] [7] ... 赤(R・0～255)
      [2] [5] [8] ... 青(B・0～255)

<リピート> を指定すると、その数だけ配列の値を
繰り返して適用します (WS.LED 1,3 で 3 個の LED に
同じ色を設定)。

SDON 中は SD カードと共有するポート 1・3・4 への
送信がブロックされます。
