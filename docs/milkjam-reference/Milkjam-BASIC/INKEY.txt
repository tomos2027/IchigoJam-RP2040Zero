INKEY
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
キーボードから 1 文字入力します。

[ コマンド 書式 ]
INKEY()

[ 例 ]
10 K=INKEY()
20 IF K ? CHR$(K)
30 GOTO 10

[ 解説 ]
USB キーボードや UART から 1 文字入力します。
入力がなければ 0 を返します。
キーコードは ←=28 (LEFT)・→=29 (RIGHT)・↑=30 (UP)・
↓=31 (DOWN)・SPACE=32 です。
入力待ちをする場合は INPUT を使用して下さい。
