OUT
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
外部出力を出します。

[ コマンド 書式 ]
OUT <数1>{,<数2>}

[ 例 ]
OUT 1,1
OUT 0,255

[ 解説 ]
<数1> で指定した OUT 端子に 0 または 1 (<数2>) を出力します。
<数1> に 0 を指定すると <数2> をビットパターンとして
全端子へまとめて出力します。

Milkjam の OUT 端子と GPIO の対応は次のとおりです。

    OUT1  GP8  (SD カード MISO と共有)
    OUT2  GP9
    OUT3  GP10 (SD カード CLK と共有)
    OUT4  GP11 (SD カード MOSI と共有)
    OUT5  GP22
    OUT6  GP21
    OUT7  GP2  (LED と共通)
    OUT8～11  IN1～4 に切り替えた端子

<数2> に -1 を指定すると IN (フロート) へ、
-2 を指定するとプルアップ付き IN へ切り替わります。
SDON 中は SD カードと共有する OUT1・OUT3・OUT4 への
出力がブロックされます。
