SOUND
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
音の再生状態を検出します。PSG レジスタを直接操作します。

[ コマンド 書式 ]
SOUND()  … 再生状態の検出 (関数)
SOUND <レジスタ>,<値>  … PSG レジスタ操作 (命令)

[ 例 ]
50 IF SOUND() GOTO 50
SOUND 0,50:SOUND 1,7:SOUND 7,#38:SOUND 8,10

[ 解説 ]
関数形式 SOUND() は音を発生している時に 1、
出していない時に 0 を返します。

命令形式 SOUND <レジスタ>,<値> は PSG (AY-3-8910 互換) の
レジスタ R0-R13 に直接書き込みます。
<レジスタ> は 0～13、<値> は 0～255 です。

    R0-R2   チャンネル A/B/C 音程 (12bit レジスタペアの下位)
    R3-R5   チャンネル A/B/C 音程 (上位)
    R6      ノイズ周期
    R7      ミキサー設定 (音色 ON/OFF)
    R8-R10  チャンネル A/B/C 音量 (0～15、16 でエンベロープ)
    R11-R12 エンベロープ周期 (12bit レジスタペア)
    R13     エンベロープ形状

SOUND <レジスタ>,<値> を実行すると PSG 多声モードに
切り替わります (単声 PLAY・BEEP で PWM トーンモードに戻ります)。
PLAY を参照して下さい。
