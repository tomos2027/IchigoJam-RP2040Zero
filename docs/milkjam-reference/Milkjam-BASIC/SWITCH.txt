SWITCH
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
映像出力を切り替えます。

[ コマンド 書式 ]
SWITCH {<モード>{,<回転>}}

[ 例 ]
SWITCH
SWITCH 1
SWITCH 2,1

[ 解説 ]
映像出力を切り替えます。<モード> の値は次のとおりです。

    0  DVI (HDMI) 出力 720x480p60 (TV 互換 480p)
       GP12-19 (Pico DVI sock)
    1  NTSC コンポジット出力 (カラー対応)
       GP3 (75Ω+560pF の外部回路経由)
    2  TFT 液晶 ILI9341 出力 (白黒)
       GP12-16 (HDMI ピンと排他 → LCDON/LCDOFF で管理)

<モード> を省略すると DVI→NTSC→TFT→DVI の順で
切り替えます (LCDON/LCDOFF で禁止されているモードはスキップ)。

SWITCH 2 の場合は第 2 引数で TFT の向きを指定できます。
1 で 180° 回転、0 で通常向きに戻ります。

モードと回転設定はフラッシュに保存され、
次回起動時も同じモードで起動します。
NTSC モードは CPU が 157.5MHz 駆動のため、
DVI・TFT (270MHz) より BASIC の実行速度が遅くなります。
TFT と SD カードは SPI1 を共用するため、
SDON 中 (SD 読み書き中) は画面更新が一時停止します。

LCDON・LCDOFF を参照して下さい。
