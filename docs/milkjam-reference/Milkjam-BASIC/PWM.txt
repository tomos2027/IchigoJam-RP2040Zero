PWM
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
OUT 端子にパルス幅変調を出力します。

[ コマンド 書式 ]
PWM <端子>,<パルス幅>{,<パルス周期>}

[ 例 ]
PWM 2,150
PWM 5,630,-1260

[ 解説 ]
<端子> は 1～6 で OUT1～6 に対応します (もう片方は GND を用います)。
<パルス幅> は 0.01 ミリ秒単位 (100 = 1 ミリ秒) で
HIGH になる時間を設定します。サーボには 100～200 を用います。
<パルス周期> は 0.01 ミリ秒単位のパルス周期です。
省略時は 2000 (20 ミリ秒・50Hz) です。

<パルス周期> にマイナスの値を指定すると高速モードになり、
<パルス幅>・|<パルス周期>| が 1/48 マイクロ秒単位の
48MHz カウンタで動作します。
例えば PWM 5,630,-1260 は 約38kHz・デューティ 50% で、
IR.OUT (赤外線送信) と同じキャリアです。

SDON 中は SD カードと共有する OUT1・OUT3・OUT4 への
PWM 出力がブロックされます。
