SAVE
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
プログラムを保存します。

[ コマンド 書式 ]
SAVE {<数>}
SAVE <数>,1

[ 例 ]
SAVE 1
SAVE 200
SAVE 201,1

[ 解説 ]
<数> の番号でプログラムを保存します。
省略した場合は前回使用した番号です。

Milkjam の保存先は次のとおりです。

    0～24     内蔵フラッシュ (25 本)
    100～131  外部 EEPROM (32 本)
    200～299  SD カード (SDON 中のみ)

SD カード (200-299) は通常 P<番号>.IJB (バイナリ・
BASIC 内部形式) に保存します。
<数> の後に ,1 を付けると P<番号>.BAS (アスキー形式・
UTF-8) に保存し、PC のエディタでそのまま
閲覧・編集できるようになります。
半角カナは 1 文字 3 バイトになるため、
4096 バイト (プログラム領域) を超えると保存できません。
漢字は非対応です (かなで記述して下さい)。

SD カードへの保存では CRC 検査・書込み後の
全バイト照合を行います。失敗時は
SD read/write error の詳細を表示します。

起動時にプログラムを自動実行したい場合は、
プログラムの先頭行に ARUN を入れ SLEEP で終了します
(起動 2 秒後に LRUN で実行されます。ESC キーで
Break して停止できます)。
