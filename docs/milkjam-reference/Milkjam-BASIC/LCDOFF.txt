LCDOFF
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
TFT 液晶を無効化します。

[ コマンド 書式 ]
LCDOFF

[ 例 ]
LCDOFF
SWITCH 0

[ 解説 ]
TFT 液晶を無効化します (LCD モード中は
HDMI (DVI) モードへ切り替わります)。
以後 SWITCH 2 (LCD) への切り替えはブロックされ、
実行すると LCD disabled (LCDON to use) と表示して
切り替えを行いません (プログラムは継続します)。

排他状態はフラッシュに保存されます。
排他の詳細は LCDON を参照して下さい。
LCD を使うには LCDON を実行して下さい。
