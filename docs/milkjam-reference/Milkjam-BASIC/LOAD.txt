LOAD
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
プログラムを読み出します。

[ コマンド 書式 ]
LOAD {<数>}

[ 例 ]
LOAD 1
LOAD 200

[ 解説 ]
<数> の番号でプログラムを読み出します。
省略した場合は前回使用した番号です。
SD カードから読む場合は現在のプログラムを消さずに読めます
(読み込みに成功した時点で置き換わります)。

Milkjam の保存先は次のとおりです。

    0～24     内蔵フラッシュ (25 本)
    100～131  外部 EEPROM (32 本)
    200～299  SD カード (SDON 中のみ)

SD カード (200-299) は P<番号>.IJB (バイナリ) を優先して読み、
なければ P<番号>.BAS (アスキー形式・UTF-8) を自動判読します。
.BAS の読み込みでは BOM 対応、全角英数→半角、
全角カナ→半角カナの変換を行います。
SAVE・LRUN を参照して下さい。
