BEEP
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
単音を鳴らします。

[ コマンド 書式 ]
BEEP {<数1>{,<数2>}}

[ 例 ]
BEEP
BEEP 10,30

[ 解説 ]
<数1> に周期 (0～32767)、<数2> に長さ (1/60 秒単位) を指定します。
両方とも省略できます。
音は GP20 (SOUND 端子) から出力されます。
GP20 と GND の間に圧電サウンダーやスピーカを接続して下さい。

BEEP はハード PWM の方形波 (トーンモード) で発音します。
多声演奏は PLAY を参照して下さい。
