LET
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
数を変数に記憶します。

[ コマンド 書式 ]
LET <変数>,<数>
LET [<配列番号>],<数>{,<数2>...}

[ 例 ]
LET A,100
LET [0],1,2,3

[ 解説 ]
<数> をアルファベット 1 文字の変数や配列の値として記憶します。
配列へは LET [<配列番号>],<数>,<数2>... で連続代入できます。

Milkjam の配列は [0]～[357] の 358 個です (4K 版拡張)。
[0]～[101] は #800-#8FF、[102]～[357] は #C00-#DFF に
配置されています (HELP を参照)。
配列番号には式も使用できます。
