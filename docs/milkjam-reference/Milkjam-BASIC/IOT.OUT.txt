IOT.OUT
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
sakura.io モジュールへデータを送信します。

[ コマンド 書式 ]
IOT.OUT <値>
IOT.OUT <送信内容>,<長さ>

[ 例 ]
IOT.OUT 1
IOT.OUT "Milkjam ",7

[ 解説 ]
I2C 接続した sakura.io モジュールの
データ即時送信コマンド (Q=#21) を用いて値を送出します。
送出時の ch は 0 固定です。

<送信内容> には仮想メモリの番地や文字列を指定できます。
<長さ> は 8 の倍数で、128 バイトを超える場合は
128 バイト毎に送信します。

Milkjam では ThingsBoard への送信は EJ コマンドを
使用して下さい (EJ を参照)。
