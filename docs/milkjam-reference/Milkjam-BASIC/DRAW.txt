DRAW
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
画面に線を引きます。

[ コマンド 書式 ]
DRAW <数1>,<数2>{,<数3>,<数4>}{,<数5>}

[ 例 ]
DRAW 0,0,62,46
DRAW 10,10,1

[ 解説 ]
<数1>,<数2> の座標から <数3>,<数4> の座標へ線を引きます。
<数3>,<数4> を省略すると 1 ドットの点を描きます。
座標の最大値は画面モードにより異なります (最大 63x47)。

<数5> は次のとおりです。省略時は 1 です。

    1 線を引く (描く)
    0 線を消す
    2 反転する

POINT で点の有無を調べられます。
