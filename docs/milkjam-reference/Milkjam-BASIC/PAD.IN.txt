PAD.IN
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
全センサー値と RTC 時刻を配列へ一括格納します。

[ コマンド 書式 ]
PAD.IN [<配列番号>]

[ 例 ]
10 PAD.IN [100]
20 ?[100]/10;"C ";[101]/10;"% ";[102]/10;"hPa"

[ 解説 ]
全センサー値 + RTC 時刻を 16 値の配列へ一括格納します。
配列番号には変数・式も使えます ([n+15] が [357] 以下に
なる範囲で指定して下さい)。
値は 1 秒周期のバックグラウンド読取値で、
SET* キャッシュ・オフセットが適用された値です。

    [n+0]   温度 (BME280)        0.1℃
    [n+1]   湿度 (BME280)        0.1%RH
    [n+2]   気圧 (BME280)        0.1hPa
    [n+3]   外気温 1 (DS18B20)   0.1℃
    [n+4]   外気温 2 (DS18B20)   0.1℃
    [n+5]   照度 (BH1750)        lux
    [n+6]   照度 2 (LTR390)      0.1lux
    [n+7]   UV カウント (LTR390) cps
    [n+8]   距離 (VL53L0X)       0.1cm (無効=0)
    [n+9]   状態フラグ
            bit0=BME280 / bit1=BH1750 / bit2=LTR390 /
            bit3=VL53L0X / bit4=DS18B20 / bit5=RTC (1=認識済)
    [n+10]～[n+15]  年/月/日/時/分/秒  JST (RTC なし=0)

センサーは全て任意接続で、接続したものだけ自動認識します。
