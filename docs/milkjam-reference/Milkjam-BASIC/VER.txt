VER
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
バージョン番号を返します。

[ コマンド 書式 ]
VER({<数>})

[ 例 ]
?VER()

[ 解説 ]
Milkjam Basic のバージョン番号を返します。

    VER()    16130 (IchigoJam BASIC 1.6.1 4K 版ベース)
    VER(1)   9 (RP2350)

IOTPAD 機能のバージョンは EJ "VER" で確認できます
(現在 1.0.0.00)。
