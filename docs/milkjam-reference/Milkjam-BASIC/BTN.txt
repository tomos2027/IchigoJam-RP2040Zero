BTN
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
ボタンやキーの押下状態を返します。

[ コマンド 書式 ]
BTN({<数>})

[ 例 ]
?BTN()
IF BTN(SPACE) GOTO 10

[ 解説 ]
<数> を省略または 0 にした場合は本体ボタン (GP28) の押下状態を返します。
押されていれば 1、そうでなければ 0 です。

<数> にキーコード (LEFT・RIGHT・UP・DOWN・SPACE・X(88) や
ASCII 文字コード) を指定すると、USB キーボードの
対応するキーが押されていれば 1 を返します。

<数> に -1 を指定するとビットパターンで返します。

    bit0  ← (LEFT)
    bit1  → (RIGHT)
    bit2  ↑ (UP)
    bit3  ↓ (DOWN)
    bit4  SPACE
    bit5  X

GPIO ピンの入力は IN を使用して下さい。
