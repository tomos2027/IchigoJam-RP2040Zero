IOT.IN
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
sakura.io モジュールからデータを受信します。

[ コマンド 書式 ]
IOT.IN()

[ 例 ]
A=IOT.IN()

[ 解説 ]
I2C 接続した sakura.io モジュールの
データ受信コマンド (Q=#30) を用いて
受信キュー先頭にあるデータを得ます。
受信データがない場合は 0 を返します。

Milkjam では WiFi・ThingsBoard 送信・各種センサーは
EJ コマンドと PAD.IN を使用して下さい
(IOTPAD 機能の項目や EJ を参照)。
