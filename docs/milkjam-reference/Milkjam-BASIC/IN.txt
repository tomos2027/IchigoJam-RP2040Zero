IN
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
外部入力を読み取ります。

[ コマンド 書式 ]
IN({<数>})

[ 例 ]
?IN(1)
?IN()

[ 解説 ]
<数> で指定した IN 端子の入力状態 (0 または 1) を返します。
<数> を省略すると全端子のビットパターンで返します。

Milkjam の IN 端子と GPIO の対応は次のとおりです。

    IN1  GP27 (DS18B20 と共有)
    IN2  GP26
    IN3  GP6  (SD カード CS と共有)
    IN4  GP7  (SD カード検出と共有)
    IN5～8  OUT1～4 を IN に切り替えた端子
    IN9  本体ボタン (GP28・BTN)
    IN10～11  OUT5～6 を IN に切り替えた端子

SDON 中は SD カードと共有する IN3・IN4 を読みません。
IN1 は DS18B20 を使用する場合、
EJ "DS18B20",1 で OneWire 用に切り替えます。
