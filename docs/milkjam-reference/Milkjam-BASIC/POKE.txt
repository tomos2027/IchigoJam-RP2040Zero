POKE
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
メモリに書き込みます。

[ コマンド 書式 ]
POKE <数1>,<数2>

[ 例 ]
POKE #700,255,129,129,129,129,129,129,255

[ 解説 ]
<数1> の仮想メモリ番地へ <数2> を書き込みます。
コンマ区切りで連続書き込みできます
(例: POKE #700,1,2,3)。
メモリマップは HELP を参照して下さい。
プログラム領域を書き換えるとプログラムが
壊れる事にご注意下さい。
