EJ
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
IOTPAD 機能の各種コマンドを実行します。

[ コマンド 書式 ]
EJ "<コマンド>"{,"<引数>"}
EJ <コマンド>{,<引数>}
EJ <コマンド>,<変数>
EJ(<コマンド>)

[ 例 ]
EJ "SETSSID","MYWIFI"
EJ "APC"
EJ GETTEMP,A
?EJ("GETTEMP2")

[ 解説 ]
WiFi・時刻・センサー・ThingsBoard・OLED を操作する
IOTPAD 機能のコマンドを実行します。
引用符は省略できます (EJ APC と EJ "APC" は同じ)。
コマンド名は大文字化して一致判定します。

【コマンド形式】 EJ "<コマンド>"{,"<引数>"}
結果を画面に表示します。

【代入形式】 EJ <コマンド>,<変数>
数値結果を変数・配列へ代入し、画面出力しません。
対象は数値を返すコマンド (GET 系・SYNCTIME・SENDTB など) です。
変数は 1 文字 + 行末のみ代入先と認識します。
EJ GETTIME,[n] は配列 6 スロット [n]～[n+5] に
年/月/日/時/分/秒 (JST) を代入します。

【関数形式】 EJ("<コマンド>")
数値結果を式の中で使用できます
(数値を返さないコマンドはエラー)。

【値の 16 進入力】 SETSSIDHEX・SETPWDHEX・SETTOKENHEX で
2 桁×N バイトの 16 進で入力できます
(小文字・記号を含む値を正確に入力する経路)。

【主なコマンド】

  WiFi・時刻:
    SETSSID / SETPWD / SETTOKEN <値>   設定保存 (フラッシュ不揮発)
    SETSSIDHEX / SETPWDHEX / SETTOKENHEX <16進>
    APC        接続 (最大 15 秒) → Connected:<IP> /
               Connect Failed:<link 状態>
    APD        切断
    APS        接続状態 (1/0)
    RECONNECT{,<分>}  自動再接続間隔 (0=OFF、フラッシュ保存)
    SYNCTIME   NTP 時刻同期 + RTC 書込 (同期済みなら即座に返す)
    GETTIME    RTC 時刻を JST YYYY-MM-DDTHH:MM:SS で表示
    SETTIME "YYYY-MM-DDTHH:MM:SS"  JST 指定で RTC へ書込
    GETIP / GETSSID / GETPWD / GETTOKEN   設定値表示

  センサー値取得 (表示値=実数値、代入値=0.1 単位。
  GETxxx2 形は代入値 ×100):
    GETTEMP / GETTEMP2       温度 (BME280、0.1℃)
    GETEXTTEMP1 / GETEXTTEMP2   外気温 1 (DS18B20)
    GETEXTTEMP12 / GETEXTTEMP22 外気温 2 (DS18B20)
    GETHUM / GETHUM2         湿度 (0.1%RH)
    GETPRESS / GETPRESS2     気圧 (0.1hPa)
    GETLUX / GETLUX2         照度 (BH1750、lux 整数)
    GETLTRLUX / GETLTRLUX2   照度 2 (LTR390、0.1lux)
    GETLTRUV / GETLTRUV2     UV 指数相当
    GETLTRUVCPS / GETLTRUVCPS2  UV カウント (cps)
    GETDISTANCE / GETDISTANCE2  距離 (VL53L0X、0.1cm、無効=0)
    GETALL                   全センサー値の JSON 一括

  値のオーバーライド・較正:
    SETTEMP / SETEXTTEMP1 / SETEXTTEMP2 / SETHUM / SETPRESS /
    SETLUX / SETLTRLUX / SETLTRUV / SETLTRUVCPS / SETDISTANCE <値>
        値を文字列キャッシュに固定 (以降の GET*・送信はこの値)
    SETALL     現在値を全キャッシュへ一括保存
    SETCLEAR   キャッシュ全解除
    OFFSETTEMP / OFFSETHUM / OFFSETPRES / OFFSETEXTTEMP1 /
    OFFSETEXTTEMP2 <float>
        オフセット設定 (フラッシュ保存)
    OFFSETCLEAR  全オフセット = 0
    GETOFFSET  オフセット 5 種の表示
    CALIBEXTTEMP  外気温 1 を基準に本体温度と外気温 2 を自動較正
    DS18B20{,0/1}  GP27 の OneWire/IN1 切替 (フラッシュ保存)

  ThingsBoard:
    SENDTB            即時送信 → TB Code:200
    SENDTB,<秒>       自動送信間隔 (0=OFF、フラッシュ保存)
    GETQUEUE          Queue:n/8 (RAM)
    FLUSHQUEUE        キュー全送信 → Flushed:n (未接続=No WiFi)
    CLEARQUEUE        キュー全消去
    QUEUESTORE        保存先表示 (常に RAM (fixed))

  OLED 制御:
    OLEDON / OLEDOFF  直接描画モードの開始/終了
    OLEDCLEAR         画面クリア+カーソル原点
    OLEDCUR x,y       カーソル設定 (baseline 座標系)
    OLEDPRINT / OLED <テキスト>  直接描画
    OLEDFONT{,0-4}    フォント切替 (5x7/6x12/8x13 標準/9x15/10x20)
    GETFONT           現在のフォント表示
    OLEDPAGE,1-5 / NEXTSCR  画面切替 (5 画面を巡回)

  その他:
    VER        IOTPAD バージョン (1.0.0.00)
    GETCONF    総合状態表示
    GETRESET   リセット原因 (POR=電源投入 / WDT=ウォッチドッグ)
    HELP       全コマンド一覧

未定義のコマンドは Unknown:<コマンド> を表示します。
センサー値の一括取得は PAD.IN も使用できます。
