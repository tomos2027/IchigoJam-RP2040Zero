HELP
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
メモリマップを表示します。

[ コマンド 書式 ]
HELP

[ 例 ]
HELP

[ 解説 ]
仮想メモリのマップを表示します。

    #000-#6FF  キャラクターパターン #00～#DF (読み取り専用)
    #700-#7FF  書換可能キャラクターパターン (PCG) #E0～#FF
    #800-#8FF  変数 A～Z と配列 [0]-[101]
    #900-#BFF  画面キャラクターコード (VRAM) 32x24
    #C00-#DFF  拡張配列変数 [102]-[357] (4K 版)
    #E00-      プログラム

PEEK・POKE・COPY・USR で使用する仮想メモリの位置を
確認する際に使用します。
