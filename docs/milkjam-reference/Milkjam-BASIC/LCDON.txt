LCDON
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
TFT 液晶を有効化します。

[ コマンド 書式 ]
LCDON

[ 例 ]
LCDON
SWITCH 2

[ 解説 ]
TFT 液晶 (ILI9341・GP12-16) を有効化し、
TFT (LCD) モードへ切り替えます。
以後 SWITCH 0 (HDMI) への切り替えはブロックされ、
実行すると HDMI disabled (LCDOFF to use) と表示して
切り替えを行いません (プログラムは継続します)。

TFT 液晶と Pico DVI sock (HDMI) は GP12-19 のピンを
共用しているため、両方を接続したまま信号を流さないよう
排他で管理します (安全担保)。
排他状態はフラッシュに保存され、再起動後も維持されます。

NTSC (GP3) は排他ピンではないため、
どちらの状態でも切り替え可能です。
NTSC モード中に LCDON を実行した場合は排他設定だけを
変更します (モードは維持。その後 SWITCH 2 で LCD へ)。
LCDOFF を参照して下さい。
