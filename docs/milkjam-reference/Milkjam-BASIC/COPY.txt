COPY
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
メモリをコピーします。

[ コマンド 書式 ]
COPY <数1>,<数2>,<数3>

[ 例 ]
COPY #900,#900+32,32*23

[ 解説 ]
<数1> のアドレスへ、<数2> のアドレスから <数3> の長さ分
メモリをコピーします。
<数3> にマイナスの数を指定するとコピー方向が逆になります
(アドレスの大きい側からコピー)。
仮想メモリの内容は HELP を参照して下さい。
