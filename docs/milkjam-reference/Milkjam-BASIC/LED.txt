LED
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
ランプを点灯・消灯します。

[ コマンド 書式 ]
LED <数>

[ 例 ]
LED 1
LED 0

[ 解説 ]
GP2 (LED 端子) に接続したランプを点灯・消灯します。
<数> は 0 以外で点灯、LED 0 で消灯です。
LED は OUT 7 と共通の端子です (OUT 7,n と LED n は同じ動作)。
WS.LED のポート 7 も同じピンです。

Raspberry Pi Pico 2 W 基板上の LED は WiFi チップ (CYW43) 経由で
点滅表示 (ハートビート・診断) に使用されており、
LED コマンドでは制御できません。
基板 LED を点灯させるには WS.LED 0,1 を使用して下さい。
