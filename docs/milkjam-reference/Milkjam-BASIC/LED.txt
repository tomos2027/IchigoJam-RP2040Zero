LED
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
ランプを点灯・消灯します。

[ コマンド 書式 ]
LED <数>

[ 例 ]
LED 1
LED 0

[ 解説 ]
基板内蔵 WS2812 (GP16) を制御します。
<数> は 0 以外で光度半分の赤色に点灯、LED 0 で消灯です。
GP2 (LED 端子) 側面パッドを制御するには OUT 7,n または WS.LED 8,n を使用して下さい。
WS.LED のポート 7 は GP15 (外部WS2812) です。

※本基板 (Waveshare RP2040-Zero) では LED コマンドで基板内蔵 WS2812 (GP16) を
直接制御できます。Pico 2 W 等、別基板では WS.LED 0,1 を使用して下さい。
