## 1. 概要とアーキテクチャ

| 項目 | 内容 |
|---|---|
| 音源 | **AY-3-8910 (MSX PSG) 互換エミュレーション、3声** (chA/chB/chC) |
| 出力 | **GP14** (側面パッド9)、PWM方形波 |
| 音声エンジン | **core1** 専用 (約56kHz = 18µs周期のオーディオ割込み)。core0 (映像・BASIC) と分離されているため、画面表示やUSBキーボードに影響を与えません |
| 出力方式 | 単声: ハードPWM方形波 (クリーンな音) / 多声: 3ch混合デューティ出力 (約56kHz割込み) |
| 必要機器 | GP14は3.3V/数mAのロジック出力のため、**アンプ+スピーカーが必要** (§2) |

```
BEEP / PLAY 1声  ──→ ハードPWM方形波 (GP14)          ┐
PLAY 2〜3声      ──→ PSGエミュ (core1) → 3ch混合PWM ┘→ GP14 → アンプ → スピーカー
SOUND            ──→ PSGエミュ (core1) → 3ch混合PWM ┘
```

---

## 2. 音声出力と配線

GP14の出力は **0〜3.3Vの方形波 (供給電流は数mA)** です。
負荷を直接鳴らさず、**アンプまたはトランジスタ等のドライバを介して**駆動してください。

- **小型アンプモジュール + スピーカー (推奨・動作確認済み)**:
  GP14 (側面パッド9) → アンプ入力、GND → アンプのGND (共通GND)
- **圧電ブザー (パッシブ) の直結は実用音量になりません**:
  3.3V/数mAでは圧電素子を十分に駆動できず、単声・多声ともほとんど聞こえません
  (本機の故障ではありません)。圧電を使う場合は NPNトランジスタ
  (ベース抵抗 例: 1kΩ) 等のドライバ経由で駆動してください
- 無音時の出力はLOWに固定されます
- GP14はPWM命令のOUTポートと共有しません (PWMの影響を受けません)

## 3. 動作モード (単声PWM / 多声PSG)

| モード | 開始条件 | 出力方式 |
|---|---|---|
| **単声PWMモード** | `BEEP`、`PLAY` 1声、全声演奏終了後の自動復帰 | ハードPWM方形波 (音程はPWM周波数そのもの) |
| **多声PSGモード** | `PLAY` 2〜3声、`SOUND` 実行 | 約56kHz割込みでAY-3-8910相当の3chをPWMデューティ混合出力 |

- 多声PLAY演奏中に `BEEP` または1声PLAYを実行すると、**演奏を打ち切って単声モードへ戻ります**
- **多声PLAYは全声の演奏終了で自動的に単声モードへ戻ります**
- 多声モードでは MMLの `V` (音量) が有効、単声PWMモードでは無効 (音量固定)

## 4. PLAY — 多声MML演奏(最大3声)

```
PLAY ["MML1"[,"MML2"[,"MML3"]]]
PLAY                    … 全声停止
```

- カンマ区切りで最大3声。**声1→chA、声2→chB、声3→chC**
- **新しいPLAYは前の演奏を打ち切って新規開始します** (MSXのようなキュー積みは
  ありません。連続演奏は `SOUND()` で完了待ちしてください — §10のサンプル参照)
- `PLAY A,A,D` のように**文字列を代入した変数**も指定できます
- 1声だけの指定は従来どおりの単声PWMモードで鳴ります

### MMLコマンド一覧

| コマンド | 動作 | 備考 |
|---|---|---|
| `C` `D` `E` `F` `G` `A` `B` | 音符 | 直後の `+`/`#` で半音上、`-` で半音下。**BとCには効きません** (B+はBのまま、C-はCのまま — オクターブをまたぎません) |
| `R` | 休符 | |
| `O0`-`O9` | オクターブ指定 | **半角英字「O」です (数字の0と間違えないように)**。数字は1桁のみ (O10は不可)。既定 O3 |
| `<` / `>` | **オクターブ上 / 下** | `<` で1オクターブ上げ、`>` で1オクターブ下げます |
| `L1`-`L32` | 既定音符長 | 既定は `L4` 相当 (4分音符)。直後に `.` で符点も可 |
| `T<数>` | テンポ (声ごと) | 既定 T120。32-255程度を推奨 |
| `V0`-`V15` | **音量** | 声ごとのPSG音量 (**多声モードで有効**、単声PWMでは無効)。15を超える値は15に切詰め |
| `N0`-`N255` | 音程を数値で直接指定 | 周波数 = 7830÷数値 Hz (N30≈261Hz)。255を超える値は255に切詰め |
| `$` | リピート開始位置 | MML末尾でこの位置へ戻る (無限ループ)。各声ごとに指定 |
| `.` | 符点 | 直前の音符/既定長の長さ×1.5 |
| (スペース) | 無視 | 読みやすさのため自由に挿入可 |

- 音符の直後の数字 (1-32) はその音の長さ: `C4`=4分音符、`C8`=8分音符。
  対応する長さは 1/2/4/8/16/32 です (それ以外の数字も指定できますが動作は不定)
- 対応していない記号 (`&` タイ等) が現れると**その時点で演奏終了**です
  (`$` が指定されていればリピート位置へ戻ります)

### 使用例

```
PLAY "CDE"                … 単声 (従来どおり)
PLAY "CDE","FGA"          … 2声の和音
PLAY "O4C4E4G4","O4E4G4O5C4","O4G4O5C4E4"   … 3声
PLAY "$CDE","$EFG"        … 2声BGMの無限ループ
PLAY "C V5","C V15"       … 音量を変えた2声
```

## 5. TEMPO

```
TEMPO n
```

- テンポを指定します (**32-255程度を推奨**、既定120)
- **PLAYを実行するたびにテンポは120にリセットされます**
  (IchigoJam_P準拠の仕様)。曲ごとのテンポ指定はMMLの `T` コマンドを使ってください
- MMLの `T` は**声ごと**に個別設定できます (声ごとのテンポ状態を持ちます)
- 実行した瞬間に反映されます (演奏中の変更も可能)

## 6. BEEP

```
BEEP [tone[,len]]
```

- 既定 `BEEP 10,3` (783Hz、約50ミリ秒)
- 周波数 = **7830÷tone Hz**、長さ = len (フレーム数 ≈ 16.7ms単位)
- **常にPWM方形波 (単声モード) で発音します**。多声PLAY演奏中やSOUND持続音を
  鳴らした後に実行すると、それらを停止してPWMモードへ戻ります

## 7. SOUND — PSGレジスタ直接操作

```
SOUND reg,val
SOUND(reg,val)          … 括弧形式
```

- reg=0-13、val=0-255。**AY-3-8910 (MSX互換) のレジスタに直接書き込みます**
- 実行すると多声PSGモードに入り、次の単声PLAY/BEEPでPWMモードへ自動戻りします
- 多声PLAYとSOUNDは同じ3chを共有します (相互に上書きします)

### レジスタ一覧

| reg | 機能 |
|---|---|
| 0, 1 | chA トーンピリオド (下位/上位8bit、有効12bit) |
| 2, 3 | chB トーンピリオド |
| 4, 5 | chC トーンピリオド |
| 6 | ノイズ周期 (0-31) |
| 7 | ミキサー (bit0-2=各chトーン、bit3-5=各chノイズ、**0=有効**) |
| 8, 9, 10 | chA/B/C 音量 (0-15、+16でエンベロープ使用) |
| 11, 12 | エンベロープ周期 (下位/上位8bit) |
| 13 | エンベロープ形状 (bit3=continue、bit2=attack、bit1=alternate、bit0=hold) |

### トーン周波数

```
周波数 ≈ 1777777 ÷ (2 × ピリオド) Hz
```

- 例: ピリオド2020 (R0=228、R1=7) → 約440Hz
- **ピリオドは12bitのため約218Hzが下限**です (実機AY-3-8910と同じ)。
  PLAYのMMLは内部16bit拡張でO1 (約32Hz) まで対応します

### ミキサー (R7) のよく使う値

| 値 | 意味 |
|---|---|
| 254 | chAトーンのみ |
| 253 | chBトーンのみ |
| 251 | chCトーンのみ |
| 247 | chBノイズのみ |
| 63 | 全OFF |

### 使用例

```
SOUND 0,228:SOUND 1,7:SOUND 7,254:SOUND 8,15   … chA 440Hzトーン
SOUND 8,0                                      … 停止
SOUND 6,4:SOUND 7,247:SOUND 9,12              … chBノイズ
SOUND 11,3:SOUND 12,217:SOUND 13,8:SOUND 8,16 … 440Hzに約0.5秒減衰を繰返し
```

## 8. SOUND() 関数

```
?SOUND()
```

- PLAY/BEEP (声A) の発声中=1、そうでなければ0を返します
- **SOUND命令の持続音は含みません**
- 連続演奏の完了待ちに使えます:
  ```bas
  PLAY A,A,D
  IF SOUND() GOTO 110
  ```

## 9. 音程の範囲と限界

| 経路 | 範囲 | 備考 |
|---|---|---|
| MML音符 (`O`/`<`/`>`) | O1 (約32Hz) 〜 O6 (約1008Hz) | 内部16bit拡張。**O1/O2は小型スピーカーの再生限界を下回るため、「プツッ」という立ち上がりだけ聞こえることがあります** (本機の故障ではありません。単声でも同じ) |
| MML `N` | 周波数 = 7830÷N Hz (N1≈7830Hz 〜 N255≈31Hz) | N30≈261Hz (中央ドの近く) |
| SOUND トーン | 約218Hz 〜 約8.9kHz (12bitピリオド) | 約218Hz未満は指定できません (12bit上限) |

## 10. サンプルプログラム

### 10.1 スーパーマリオ風3声BGM

```bas
10 'SUPER MARIO BROS. 3VOICE
30 A="T150O5E8E8R8E8R8C8E4G4R4O4G4R4"
40 B="T150O5C4R8O4G4R8E4R8A8R8B8R8A+8A4"
50 C="T150G8E8G8O6A4F8G8R8E4R8C8D8B8R4"
60 D="T150O3G8G8R8G8R8G8G4R4O2G4R4"
70 E="T150O3C4R8O2G4R8E4R8A8R8B8R8A+8A4"
80 F="T150O2G8O3E8G8O4A4F8G8R8E4R8C8D8O3B8R4"
90 G="T150O4G8E8G8O6A4F8G8R8E4R8C8D8B8R4"
100 PLAY A,A,D
110 IF SOUND() GOTO 110
120 PLAY B,B,E
130 IF SOUND() GOTO 130
140 PLAY C,G,F
150 IF SOUND() GOTO 150
160 GOTO 100
```

> MSX BASICの `PLAY A$+B$` のような**文字列連結はIchigoJamにはありません**
> (`+` は数値の加算になるため音が出なくなります)。テンポ (`T`) や
> オクターブ (`O`) は文字列に直接書いてください。

### 10.2 エンベロープを使った効果音

```bas
10 SOUND 11,1:SOUND 12,80:SOUND 13,0   '減衰形
20 SOUND 0,228:SOUND 1,7:SOUND 7,248:SOUND 8,16
30 WAIT 30
40 SOUND 8,0
```

## 11. 制限事項・注意

1. **文字列連結はできません**: `PLAY A$+B$` の `+` は数値加算になるため
   音が出ません。MMLは文字列リテラルまたは文字列変数を直接指定してください
2. **キュー積みはありません**: 新しいPLAYは前の演奏を打ち切ります。
   曲の連結は `SOUND()` 完了待ちで行ってください
3. **TEMPOはPLAYで120にリセットされます**: テンポ指定はMMLの `T` を使用
4. **対応しないMML記号は演奏終了**です: `&` (タイ) 等は使えません。
   `$` リピート位置があればそこへ戻ります
5. **`O` の数字は1桁です**: `O10` は `O1` と解釈された後、`0` で演奏終了します。
   高いオクターブは `>` または `<` を使用してください
6. **`B+`/`C-` はオクターブをまたぎません**: Bの半音上 (C) が必要な場合は
   次オクターブの `C` を指定してください
7. **`V` (音量) は多声モードでのみ有効**です。単声PWMモード (1声PLAY/BEEP) では
   音量固定です
8. **出力はアンプ+スピーカー必須**です (§2)
9. GP14はPWM命令 (OUTポート) と共有しません。`PWM` 命令の影響を受けません

## 12. エラー・注意一覧

| 条件 | 動作 |
|---|---|
| `PLAY` の引数が文字列でない/未代入の変数 | 音が出ない (無視) |
| `TEMPO` に 0 等の極端な値 | 演奏が極端に速く/遅くなる (32-255を推奨) |
| `SOUND` の reg が 0-13 外 | 指定が無視される場合があります |
| 多声PLAY中の `BEEP` / 1声PLAY | 演奏を打ち切って単声モードへ戻る |
| `SOUND` トーンの12bit上限超 (低音) | 約218Hzより下は指定不可 |
| O1/O2 の低音 | スピーカーの再生限界で「プツッ」音のみの場合がある |
