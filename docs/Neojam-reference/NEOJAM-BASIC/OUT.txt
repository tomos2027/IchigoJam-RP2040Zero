OUT
NEOJAM
-----------------------------------------------------------
[ 機能 ]
外部出力を出します。

[ コマンド 書式 ]
OUT <数1>{,<数2>}

[ 例 ]
OUT 1,1
OUT 0,255

[ 解説 ]
<数1> で指定した OUT 端子に 0 または 1 (<数2>) を出力します。
<数1> に 0 を指定すると <数2> をビットパターンとして
全端子 (11 ビット) へまとめて出力します。

NEOJAM の OUT 端子と GPIO の対応は次のとおりです。

    OUT1  GP8  (SD カード MISO と共有)
    OUT2  GP9
    OUT3  GP10 (SD カード CLK と共有)
    OUT4  GP11 (SD カード MOSI と共有)
    OUT5  GP12
    OUT6  GP13
    OUT7  GP2  (LED と共通)
    OUT8  GP27 (IN1 に切り替えた端子)
    OUT9  GP26 (IN2 に切り替えた端子)
    OUT10 GP6  (IN3・SD カード CS に切り替えた端子)
    OUT11 GP7  (IN4・SD カード検出に切り替えた端子)

<数2> に -1 を指定すると IN (フロート) へ、
-2 を指定するとプルアップ付き IN へ切り替わります。
SDON 中は SD カードと共有する OUT1・OUT3・OUT4
(および OUT10・OUT11 に切り替えた IN3・IN4) への
出力がブロックされます。
