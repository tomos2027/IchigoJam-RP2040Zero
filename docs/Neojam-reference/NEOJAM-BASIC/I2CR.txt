I2CR
NEOJAM
-----------------------------------------------------------
[ 機能 ]
I2C で周辺機器から読み込みます。

[ コマンド 書式 ]
I2CR(<数1>,<数2>,<数3>,<数4>,<数5>)

[ 例 ]
?I2CR(#76,#E0,0,#904,8)

[ 解説 ]
I2C バスで周辺機器からデータを読み込みます。
成功すると 0、失敗すると 1 を返します。

    <数1> I2C アドレス (8 ビット表記)
    <数2> コマンド送信アドレス
    <数3> コマンド送信の長さ
    <数4> 受信アドレス
    <数5> 受信の長さ

コマンド送信が 1 バイトの時は <数3> を、
0 バイト (送信なし) の時は <数2>・<数3> を省略できます。
I2C バスは GP4 (SDA) / GP5 (SCL) で、
センサー (ENV.IN)・IOT モジュール (IOT.IN/IOT.OUT)・
外部 EEPROM (スロット 100-131) と共有しています。
通信速度は BPS の第 2 引数で変更できます。
I2CW を参照して下さい。
