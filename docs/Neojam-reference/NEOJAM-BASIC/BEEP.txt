BEEP
NEOJAM
-----------------------------------------------------------
[ 機能 ]
単音を鳴らします。

[ コマンド 書式 ]
BEEP {<数1>{,<数2>}}

[ 例 ]
BEEP
BEEP 10,30

[ 解説 ]
<数1> に周期 (0～32767、周波数 = 7830÷数値 Hz)、
<数2> に長さ (1/60 秒単位、既定 3) を指定します。
両方とも省略できます (既定は BEEP 10,3 = 783Hz・約 50 ミリ秒)。

音は GP14 (SOUND 端子) から出力されます。
本体基板にスピーカーは実装されていないため、
GP14 → アンプ入力、GND → アンプの GND (共通 GND) と
配線して下さい。

GP14 の出力は 3.3V・数 mA のロジック方形波のため、
圧電ブザーを直結しても実用音量になりません
(圧電を使う場合はトランジスタ等のドライバを介して下さい)。

BEEP は常にハード PWM の方形波 (トーンモード) で発音します。
多声 PLAY 演奏中や SOUND 持続音の後に実行すると、
それらを停止して PWM トーンモードへ戻ります。
多声演奏は PLAY を参照して下さい。
