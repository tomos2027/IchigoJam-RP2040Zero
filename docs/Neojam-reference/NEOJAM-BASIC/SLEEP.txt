SLEEP
NEOJAM
-----------------------------------------------------------
[ 機能 ]
プログラムを休止します。

[ コマンド 書式 ]
SLEEP

[ 例 ]
10 ?"HELLO"
20 SLEEP

[ 解説 ]
プログラムを休止します。
本体ボタンを押すと起動し、LRUN 0 を実行します。

プログラムの先頭行に ARUN、最終行に SLEEP を入れると、
電源投入後にそのプログラムが自動実行されます
(起動 2 秒後に実行されます。ESC キーで Break し、
ボタンで再開します)。
