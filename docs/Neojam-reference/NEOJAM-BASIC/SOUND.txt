SOUND
NEOJAM
-----------------------------------------------------------
[ 機能 ]
音の再生状態を検出します。PSG レジスタを直接操作します。

[ コマンド 書式 ]
SOUND()  … 再生状態の検出 (関数)
SOUND <レジスタ>,<値>  … PSG レジスタ操作 (命令)
SOUND(<レジスタ>,<値>)  … 括弧形式 (命令と同じ)

[ 例 ]
50 IF SOUND() GOTO 50
SOUND 0,228:SOUND 1,7:SOUND 7,254:SOUND 8,15

[ 解説 ]
関数形式 SOUND() は PLAY・BEEP (声 A) の発声中に 1、
出していない時に 0 を返します
(SOUND 命令の持続音は含みません)。
連続演奏の完了待ちに使用できます。

命令形式 SOUND <レジスタ>,<値> は PSG (AY-3-8910 互換) の
レジスタ R0-R13 に直接書き込みます。
<レジスタ> は 0～13、<値> は 0～255 です。

    R0, R1    chA 音程ピリオド (下位/上位・計 12bit)
    R2, R3    chB 音程ピリオド
    R4, R5    chC 音程ピリオド
    R6        ノイズ周期 (0-31)
    R7        ミキサー (bit0-2=各 ch トーン、bit3-5=各 ch ノイズ。
              0=有効。例: 254=chA トーンのみ、63=全 OFF)
    R8-R10    chA/B/C 音量 (0-15、+16 でエンベロープ使用)
    R11, R12  エンベロープ周期 (下位/上位)
    R13       エンベロープ形状

トーン周波数 ≒ 1777777 ÷ (2 × ピリオド) Hz です
(ピリオド 2020 = R0 228・R1 7 で 440Hz)。
ピリオドは 12bit のため約 218Hz が下限です
(実機 AY-3-8910 と同じ。PLAY の MML は内部 16bit 拡張で
O1 (約 32Hz) まで対応します)。

SOUND <レジスタ>,<値> を実行すると PSG 多声モードに
切り替わり、次の単声 PLAY・BEEP で PWM トーンモードに
戻ります。PLAY を参照して下さい。
