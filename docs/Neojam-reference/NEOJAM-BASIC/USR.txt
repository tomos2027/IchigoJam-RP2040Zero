USR
NEOJAM
-----------------------------------------------------------
[ 機能 ]
マシン語を呼び出します。

[ コマンド 書式 ]
USR(<アドレス>{,<R0>})

[ 例 ]
?USR(#700,100)

[ 解説 ]
<アドレス> 番地からマシン語 (ARM Cortex-M0+ の
Thumb コード) を実行します。
<R0> は第 1 パラメータ (R0 レジスタ) として
マシン語から取得でき、省略時は 0 です。
R0 レジスタの値を返り値として返しますので、
LET や PRINT で使用できます。

第 2 パラメータ (R1 レジスタ) として仮想メモリの先頭
ポインタ (#000 部の該当アドレス。#000～#6FF は
実メモリに存在しないため #700 以降が有効) を渡します。

マシン語を置ける場所は #700 以降です
(HELP のメモリマップを参照)。
CHR$(224) 以降のキャラクタや配列・変数・プログラムを
破壊する事にご注意下さい。
書き込みできる仮想メモリ外のアドレスを指定した場合は
エラー Illegal argument となり実行されません。
