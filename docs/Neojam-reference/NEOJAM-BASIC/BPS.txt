BPS
NEOJAM
-----------------------------------------------------------
[ 機能 ]
シリアル通信速度や I2C 通信速度を変更します。

[ コマンド 書式 ]
BPS <数1>{,<数2>}

[ 例 ]
BPS -2304
BPS 0,100

[ 解説 ]
<数1> で UART (シリアル) の通信速度を変更します
(UART は GP0=TX・GP1=RX、初期 115,200bps)。

    0        初期値の 115,200bps
    -1       57,600bps
    -2       38,400bps
    -100 以下 指定した数の -100 倍 bps (例: -2304 で 230,400bps)
    1～32767 指定した数のまま bps を設定 (例: 9600 で 9,600bps)

1～45 は UART 分割器の上限により実効速度が約 46bps に
クランプされます (エラーにはなりません)。
速度の上限は約 3Mbps です (32767 を超える速度は
-100 倍形式で指定して下さい)。
UART コマンドは通信速度を変更しません
(表示の設定のみ。速度変更は BPS を使用して下さい)。

<数2> で I2C の通信速度を kHz 単位で指定します。
0 または省略でデフォルトの 400kHz です。
I2C バス (GP4=SDA・GP5=SCL) はセンサー (ENV.IN)・
IOT モジュール (IOT.IN/IOT.OUT)・外部 EEPROM と
共有しているため、接続した機器に合わせて設定して下さい。
