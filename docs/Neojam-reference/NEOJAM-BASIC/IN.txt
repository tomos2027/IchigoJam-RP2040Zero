IN
NEOJAM
-----------------------------------------------------------
[ 機能 ]
外部入力を読み取ります。

[ コマンド 書式 ]
IN({<数>})

[ 例 ]
?IN(1)
?IN()

[ 解説 ]
<数> で指定した IN 端子の入力状態 (0 または 1) を返します。
<数> を省略すると全端子 (11 ビット) のビットパターンで返します。

NEOJAM の IN 端子と GPIO の対応は次のとおりです。

    IN1  GP27 (ADC1・アナログ入力も可)
    IN2  GP26 (ADC0・アナログ入力も可)
    IN3  GP6  (SD カード CS と共有)
    IN4  GP7  (SD カード検出と共有)
    IN5～8  OUT1～4 を IN に切り替えた端子
    IN9  本体ボタン (GP28・BTN)
    IN10～11  OUT5～6 を IN に切り替えた端子 (GP12・GP13)

IN4 (GP7) は SD カード検出専用のため、IN() の
ビットパターンにも IN(4) の戻り値にも現れません
(常に 0 です。GPIO 出力 OUT 11 として使用できます)。

SDON 中は SD カードと共有する IN3 を読みません
(IN4 は常に読みません)。
