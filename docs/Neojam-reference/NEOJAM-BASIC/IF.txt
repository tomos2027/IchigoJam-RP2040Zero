IF
NEOJAM
-----------------------------------------------------------
[ 機能 ]
条件により実行するコマンドを分けます。

[ コマンド 書式 ]
IF <数> {THEN} <コマンド1> {ELSE <コマンド2>}

[ 例 ]
10 IF A>10 ? "BIG"
20 IF A>10 :? "BIG" :ELSE ? "SMALL"

[ 解説 ]
<数> が 0 でなければ <コマンド1> を実行し、
0 であれば <コマンド2> を実行します。
THEN・ELSE 以降は省略できます。

16 進数 (# で始まる数) の直後に THEN を省略して
A～F で始まるコマンドを使う場合は、
: で区切る必要があります。
