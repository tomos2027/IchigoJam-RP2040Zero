PCA9685.* (I2C 16ch PWM/サーボ)
NEOJAM (カラー表示・テスト実装)
-----------------------------------------------------------
[ 機能 ]
I2C接続の PCA9685 (16チャンネルPWMドライバ) で
サーボ16個やLED調光16chを制御します。

[ コマンド 書式 ]
PCA9685.SETUP <address>
PCA9685.SETFREQ <freq>
PCA9685.PWM <pin>,<value>

[ 例 ]
PCA9685.SETUP #40
PCA9685.SETFREQ 50
PCA9685.PWM 0,307

[ 解説 ]
PCA9685.SETUP : I2Cアドレス (7bit 0x40-0x7F、既定 #40) を設定し
チップを初期化します (スリープ解除+自動インクリメント+
トーテンポール出力)。SETUP が必須です (未実行で他のコマンドを
実行すると Illegal argument。CLV でも未実行に戻ります)。
PCA9685.SETFREQ : PWM周波数 24-1526Hz を設定します
(スリープ→設定→復帰で即時反映。サーボは50)。
PCA9685.PWM : チャンネル pin (0-15) に12bitデューティ
value (0-4095) を設定します (0=消灯、4095=ほぼ全開。
範囲外はクランプ)。サーボは 50Hz 設定で
value ≈ パルス幅(ms)÷20×4096 (0°=102、90°=307、180°=512)。
I2C転送の失敗は無視されます (配線・アドレス・電源を確認)。
I2C バスは GP4 (SDA) / GP5 (SCL) で、ENV.IN・EJ・
外部EEPROMと共有しています。
PCA9685 の VDD は 3.3V 推奨、サーボ/LED 電源は V+ ピンへ。
詳細は docs/PCA9685_JA.md を参照して下さい。
