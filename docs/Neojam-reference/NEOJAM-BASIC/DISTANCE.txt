DISTANCE
NEOJAM
-----------------------------------------------------------
[ 機能 ]
HC-SR04 超音波距離センサで距離を測ります。

[ コマンド 書式 ]
DISTANCE(<trig_out>, <echo_in>)

[ 例 ]
? DISTANCE(5,1)
10 D=DISTANCE(5,1):IF D<0 ?"OUT OF RANGE" ELSE ?D;" cm"

[ 引数 ]
<trig_out> : HC-SR04 の TRIG へ接続した OUT ポート (1-11、OUT コマンドと同じ割当)
<echo_in>  : HC-SR04 の ECHO へ接続した IN ポート (1-11、IN コマンドと同じ割当)

[ 戻り値 ]
距離 (cm、整数、四捨五入)。測定範囲は約 2〜400cm。
応答なし (障害物なし/範囲外) は -1 を返します。

[ 解説 ]
TRIG に 10µs の HIGH パルスを送り、ECHO の HIGH パルス幅から
距離を算出します (音速 340m/s 往復で 58µs/cm)。
内部で 10ms 間隔の 3 回測定を行い最大値を返します
(ECHO 幅は最初の反射までの時間のため測定値は真の距離以下にしか
ならず、弱エコーやバースト干渉で断続的に短く読まれるのを補正。
1 回の応答に約 30〜50ms、対象を素早く動かすと約 20ms 分の
応答遅れがあります)。最大値も 1.7cm 未満なら -1 = 範囲外です。
測定中は映像 DMA 以外の割込みを停止します (映像は維持され、
測定誤差は約 ±1cm)。
SDON 中は SD 共有ピン (OUT1/3/4、IN3/4) を指定すると -1 を返します。
ポート範囲外は Illegal argument エラーになります。

[ 配線注意 ]
HC-SR04 は 5V 駆動で ECHO は 5V 出力のため、ECHO→IN 間に
1kΩ/2kΩ 等の分圧抵抗を入れ 3.3V に下げて下さい
(RP2040 は 5V 非耐圧)。TRIG は 3.3V 駆動のまま動作します。
VCC は 5V、GND は共通に接続します。
