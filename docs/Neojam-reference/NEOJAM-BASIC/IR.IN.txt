IR.IN
NEOJAM
-----------------------------------------------------------
[ 機能 ]
赤外線リモコンの信号を受信します。

[ コマンド 書式 ]
IR.IN <ポート>,[<配列番号>]

[ 例 ]
10 IR.IN 1,[0]
20 ?HEX$([0],2);HEX$([1],2);HEX$([2],2);HEX$([3],2)
30 GOTO 10

[ 解説 ]
NEC 形式の赤外線信号を受信し、結果を配列へ格納します
(4K 版拡張・GivetakeJam_P 準拠)。
<ポート> は 1-4 で IN1～IN4 端子 (GP27/GP26/GP6/GP7) に対応し、
受信モジュール (HX1838 など) の OUT を接続します
(出力は待機時 HIGH。38kHz キャリアはモジュール側で
復調されている必要があります)。

結果の配列は次のとおりです (7 スロット使用)。

    [n+0]  生データ byte 0 (カスタムコード下位)
    [n+1]  生データ byte 1 (カスタムコード上位)
    [n+2]  生データ byte 2 (データ)
    [n+3]  生データ byte 3 (~データ)
    [n+4]  リピートフラグ (1=リピートフレーム。
           リピート時は前回の byte 0-3 を保持)
    [n+5]  エラーコード (0=成功、1=ポート不正、
           3=リーダー不一致、4/5=ビット不一致、
           6=コマンド逆数チェック不一致)
    [n+6]  モード (0=標準 NEC / 1=NEC 拡張)

受信したコードは IR.OUT で再送できます (IR.OUT を参照)。
SDON 中は共有ピンのポート 3・4 が使用できません
([n+5]=1 になります)。
