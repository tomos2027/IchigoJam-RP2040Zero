WS.SETUP
NEOJAM
-----------------------------------------------------------
[ 機能 ]
WS.LED の送信設定 (LED 数上限・読み込みオフセット・
信号反転) を行います。

[ コマンド 書式 ]
WS.SETUP <数1>{,<数2>{,<数3>}}

[ 例 ]
WS.SETUP 64
WS.SETUP 0,10,1

[ 解説 ]
<数1> : WS.LED の LED 数の上限 (0-2730、0=上限なし・既定。
        WS.MODE のモード別上限と共に適用)
<数2> : WS.MODE と同じ読み込み開始位置
        (mode0-2: 配列インデックス 0-357、mode3: バッファ
        px 位置 0-2729。省略時は現状維持)
<数3> : 1=出力信号を完全反転 (逆相ドライバ/トランジスタ経由
        駆動用。アイドル・リセット期間も Hi。WS.LED 0
        (内蔵 GP16) 以外に適用)、0=正転 (省略時は現状維持)
設定は CLV 実行時と起動時にデフォルトへ戻ります。
WS.MODE・WS.LED も参照して下さい。
