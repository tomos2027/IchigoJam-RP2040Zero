LED
NEOJAM
-----------------------------------------------------------
[ 機能 ]
基板内蔵のランプを点灯・消灯します。

[ コマンド 書式 ]
LED <数>

[ 例 ]
LED 1
LED 0

[ 解説 ]
基板内蔵の WS2812 (GP16) を光度半分の赤色で点灯・消灯します。
<数> は 0 以外で点灯、LED 0 で消灯です。
任意の色・明るさは WS.LED 0,n を使用して下さい
(内蔵 WS2812 は起動時の緑点滅・エラー時の赤高速点滅と共用)。
GP2 (OUT7) 端子に接続したランプを制御する場合は
OUT 7,n または WS.LED 8,n を使用して下さい。
