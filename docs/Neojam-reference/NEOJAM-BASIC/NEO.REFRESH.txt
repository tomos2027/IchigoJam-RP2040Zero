NEO.REFRESH
NEOJAM (カラー表示・テスト実装)
-----------------------------------------------------------
[ 機能 ]
専用バッファの内容を NEO.SETUP のポート/LED 数で送信します。

[ コマンド 書式 ]
NEO.REFRESH

[ 例 ]
NEO.PIXEL 0,"R",1
NEO.PIXEL 1,"G",1
NEO.REFRESH

[ 解説 ]
NEO.PIXEL 等で <disable>=1 を付けて書込んだ内容を
まとめて送信する際に使用します (ちらつき・送信時間の削減)。
<disable> 省略時は各コマンドが自動送信するため不要です。
NEO.SETUP・NEO.PIXEL も参照して下さい。
詳細は docs/NEO_JA.md を参照して下さい。
