WS.LED
NEOJAM
-----------------------------------------------------------
[ 機能 ]
RGB LED (WS2812B) を制御します。

[ コマンド 書式 ]
WS.LED <ポート>,<LED 個数>{,<リピート>}

[ 例 ]
10 CLV:LET[0],0,40,0
20 WS.LED 11,1
30 WS.LED 0,1

[ 解説 ]
WS2812B (WS2811・WS2812・WS2813・SK6812 など同仕様も可) を
PIO 駆動で制御します。長い LED テープを接続しても
表示や USB キーボードが乱れません。
WS2812B の DIN を接続し、GND・VCC (5V) を接続します。
複数個接続する場合は DOUT と DIN を順に接続します。
5V 駆動のテープは 3.3V ロジックでは点灯しないことがあり、
その場合は 74AHCT125 などのレベルシフタが必要です
(GND は本体と共通にして下さい)。

<ポート> で出力先を選択します (ポート選択式・4K 版拡張)。

    0  基板内蔵 WS2812 (GP16・フルカラー)。
       起動時の緑点滅・エラー時の赤点滅と共用
    1-6  OUT1～6 端子 (GP8～13)
    7  外部 WS2812 端子 (GP15)
    8  LED 端子 (GP2)
    9-11  OUT9～11 (IN2・IN3・IN4 を出力に
          切り替えた端子、GP26・GP6・GP7)

OUT8 (IN1) のみ WS.LED からは指定できません
(8 が LED (GP2) に割り当てられているため)。

<LED 個数> 分の色データを配列 [0] 以降へ、
WS2812B の場合は 緑(G)・赤(R)・青(B) の順で
0～255 の値を入れてから実行します
(WS2811・WS2813 は 赤・緑・青 の順)。

    LED 1   2   3 ...
      [0] [3] [6] ... 緑(G・0～255)
      [1] [4] [7] ... 赤(R・0～255)
      [2] [5] [8] ... 青(B・0～255)

最大 119 個 (配列 [0]-[357]) まで指定できます。

<リピート> を指定すると、その数だけ n 個分のパターンを
リセットなしで連続送信し、テープの長さ分タイル状に
繰り返します (LED 1 個では見た目は変化しません)。

WS2812 はラッチ型のため、短い <LED 個数> を送っても
前回の色が保持されます。全消灯するには CLV 後
(全配列が 0) に実行して下さい。

SDON 中は SD カードと共有するポート 1・3・4・10・11
(GP8・GP10・GP11・GP6・GP7) への送信がブロックされます。

ピクセルデータの格納形式は WS.MODE で切り替えられます。
WS.PUT・WS.MATRIX・WS.XY・RGB も参照して下さい。
