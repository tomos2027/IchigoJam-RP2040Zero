## 1. 概要

PCA9685はI2C接続の16チャンネルPWMドライバです。
1枚で **サーボ16個** または **LED調光16チャンネル** を駆動でき、
A0〜A5ピンでI2Cアドレスを変更すれば最大62枚 (992チャンネル) まで
増設できます。

| 項目 | 内容 |
|---|---|
| コマンド | `PCA9685.SETUP` / `PCA9685.SETFREQ` / `PCA9685.PWM` |
| 接続 | I2C0 (**GP4=SDA / GP5=SCL**、ENV.IN・EJ・外部EEPROMと共有) |
| アドレス | 7bit **0x40-0x7F** (既定0x40、A0-A5で+1ずつ) |
| PWM分解能 | **12bit (0-4095)** |
| PWM周波数 | 24-1526Hz (サーボは50Hz) |
| 電源 | VDD 2.3-5.5V (**3.3V推奨** — RP2040と直結可能)、サーボ/LED電源はV+ピンへ別供給 |

## 2. 配線

| PCA9685ピン | 接続先 |
|---|---|
| VDD | **3.3V** (本体の3V3パッド。5Vの場合はECHOと同様ロジックのマージンが下がるため推奨しません) |
| GND | 本体のGND (共通) |
| SCL | GP5 |
| SDA | GP4 |
| V+ | サーボ/LEDの電源 (5V等。VDDと別供給が可能) |
| LED0-PWM15 | サーボの信号線 / LED (カソード側はOEや外部抵抗を検討) |

- I2Cバス (GP4/5) には基板内部のプルアップがあります
  (外部プルアップ10kΩ程度を追加するとより安定します)
- アドレスはA0〜A5ピンをHIGHにすると +1 ずつ変わります
  (全部開放=0x40、A0=HIGHなら0x41 …)

---

## 3. PCA9685.SETUP

```
PCA9685.SETUP <address>
```

- I2Cアドレスを設定し、チップを初期化します
- `<address>`: **7bit表記 0x40-0x7F** (A0-A5未接続なら `#40`)
- 初期化内容: スリープ解除 + 自動インクリメント有効 + トーテンポール出力
- PWM周波数は**チップの現在値を維持**します (パワーオン直後は約200Hz。
  変更は `PCA9685.SETFREQ` を使用してください)
- 範囲外のアドレスは Illegal argument
- **`CLV` を実行すると未実行状態に戻ります** (再度SETUPが必要です)
- チップの電源を入れ直した場合も SETUP の再実行が必要です

---

## 4. PCA9685.SETFREQ

```
PCA9685.SETFREQ <freq>
```

- PWM周波数を **24-1526Hz** の範囲で設定します (範囲外は Illegal argument)
- 内部でプリスケール値 = round(25MHz ÷ (4096 × freq)) − 1 を計算し、
  **スリープ → 設定 → 復帰(RESTART)** のデータシート手順で反映します
  (反映は即時、出力が一瞬止まります)
- 代表値:

| freq | 用途 |
|---|---|
| 50 | サーボモータ標準 |
| 200 | パワーオン既定相当 |
| 240-1526 | LED調光 (高いほどちらつきません) |

---

## 5. PCA9685.PWM

```
PCA9685.PWM <pin>,<value>
```

- チャンネル `<pin>` (0-15) に12bitデューティ `<value>` (0-4095) を設定します
- `value=0` で消灯/ニュートラル、`value=4095` でほぼ全開
- 範囲外の値は0-4095にクランプされます
- I2C転送の失敗 (チップ未接続等) は**無視されます** (配線を確認してください)

---

## 6. サーバの使い方

50Hz設定で、パルス幅0.5-2.5msが角度0-180°に対応する一般的なサーボの場合:

```
value = パルス幅(ms) ÷ 20ms × 4096
```

| 角度 | パルス幅 | value |
|---|---|---|
| 0° | 0.5ms | 約102 |
| 90° | 1.5ms | 約307 |
| 180° | 2.5ms | 約512 |

> 製品によりパルス幅の範囲が異なります (0.5-2.5ms以外もあり)。
> 動作範囲はサーボの datasheet を確認し、範囲外の value を指定すると
> サーボが_LIMITストッパーに当たり続けて故障の原因になるため注意してください。

## 7. LED調光の使い方

```
10 PCA9685.SETUP #40
20 PCA9685.SETFREQ 1000
30 PCA9685.PWM 0,2048      ' ch0 を50%点灯
40 PCA9685.PWM 1,4095      ' ch1 を全点灯
```

- 1000Hz以上ならちらつきません
- フェード例:

```bas
10 PCA9685.SETUP #40:PCA9685.SETFREQ 1000
20 FOR I=0 TO 4095 STEP 64:PCA9685.PWM 0,I:WAIT 1:NEXT
30 FOR I=4095 TO 0 STEP -64:PCA9685.PWM 0,I:WAIT 1:NEXT
40 GOTO 20
```

## 8. サンプルプログラム

### 8.1 サーボスイープ

```bas
10 PCA9685.SETUP #40
20 PCA9685.SETFREQ 50
30 FOR I=102 TO 512
40   PCA9685.PWM 0,I:WAIT 1
50 NEXT
60 FOR I=512 TO 102 STEP -1
70   PCA9685.PWM 0,I:WAIT 1
80 NEXT
90 GOTO 30
```

### 8.2 16ch シャッフル点灯

```bas
10 PCA9685.SETUP #40:PCA9685.SETFREQ 1000
20 FOR J=0 TO 15
30  FOR I=0 TO 15:PCA9685.PWM I,0:NEXT
40  PCA9685.PWM J,4095
50  WAIT 10
60 NEXT
70 GOTO 20
```

## 9. 制限事項・注意

1. **SETUPが必須**です: 未実行で `SETFREQ`/`PWM` を実行すると Illegal argument。
   `CLV` 実行後も再度 SETUP が必要です
2. **チップの電源再投入後は SETUP を再実行**してください
   (MCU側はアドレスと初期化済みフラグのみを保持します)
3. **I2C転送の失敗は無視されます** (チップ未接続でもエラーになりません)。
   配線・アドレス・電源を確認してください
4. I2Cバス (GP4/5) は ENV.IN・EJ (OLED)・外部EEPROM (スロット100-131) と
   共有です。アドレスが異なるため同時に使用できます
5. **VDDは3.3V推奨**: 5V駆動時はRP2040の3.3Vロジックに対してVIHマージンが
   下がります (I2Cは基板内蔵プルアップ+PCA9685側プルアップで動作報告あり)
6. サーボのV+電源はPCA9685のVDDと別に供給できます (サーボ複数個は
   電流が大きいため必ず別電源を推奨)
7. **複数枚の同時制御**は可能です (SETUPでアドレスを切り替えて使用:

```bas
10 PCA9685.SETUP #40:PCA9685.PWM 0,2048
20 PCA9685.SETUP #41:PCA9685.PWM 0,1024
```
   ※SETUPを切り替えるたびにアドレスが変わるため、切替時に再描画してください)

## 10. エラー一覧

| 条件 | エラー |
|---|---|
| SETUP の address が 0x40-0x7F 外 | Illegal argument |
| SETUP 未実行で SETFREQ/PWM を実行 | Illegal argument |
| SETFREQ の freq が 24-1526 外 | Illegal argument |
| PWM の pin が 0-15 外 | Illegal argument |
| PWM の value が範囲外 | クランプ (0-4095、エラーなし) |
| I2C転送失敗 (チップ未接続) | 無視 (エラーなし) |
